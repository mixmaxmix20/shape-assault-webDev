# 🚀 ShapeAssault

---

## 🕹️ O projekcie

**ShapeAssault** to dynamiczna strzelanka 2D stworzona jako projekt zaliczeniowy na zajęcia z **Web Developmentu**. 

Głównym zamysłem i wyzwaniem technicznym projektu było wykorzystanie możliwości elementu **Canvas** do renderowania grafiki w czasie rzeczywistym.
### Główne cechy:
* **Canvas:** Cała oprawa graficzna i animacje generowane są dynamicznie za pomocą JavaScript.
* **Geometria wrogów:** Przeciwnicy to figury geometryczne o zróżnicowanych statystykach (prędkość, wytrzymałość, obrażenia).
* **System progresji:** Zdobywanie kolejnych poziomów pozwala na **ulepszanie statystyk** gracza:
    * ⚡ **Szybkość ruchu**
    * ❤️ **Ilość życia**
    * ⚔️ **Obrażenia**
* **System punktacji:** Śledzenie wyników i postępu gracza.
* Sterowanie za pomocą klawiatury i myszy.
